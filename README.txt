KLISZA — portfolio fotograficzne
Otwórz index.html w przeglądarce. Aby opublikować na GitHub Pages, prześlij całą zawartość tego folderu do głównego katalogu repozytorium.
Pliki: index.html, styles.css, script.js, favicon.svg, assets/.
Zdjęcia: Unsplash. Fonty Google Fonts wymagają internetu; przy braku połączenia strona użyje fontów systemowych.
Koncepcja demonstracyjna. Fikcyjna fotografka. Formularz nie wysyła danych: przygotowuje wiadomość do skopiowania lokalnie.
